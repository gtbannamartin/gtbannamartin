## The problem I work on

Most organizations building AI agents can build the agent. Fewer have defined what it should do, how it should behave when it gets there, or which workflow it connects to once it produces something. An agent whose output nobody consumes is a science project.

That gap, between AI capability and a client's actual systems and people, is the work.

## What I build

I build AI systems for the communities existing infrastructure has been slowest to serve.

- **[PathwayAI](https://djmpinstitute.org/pathwayai)**: a civic AI career-pathway assistant that matches Chicago residents to technology career pathways. v0 is live: one structured Claude call behind a Cloudflare Worker that holds the API key, validates input, rate-limits, and checks the JSON output. It follows a specified five-agent supervisor design with a human-in-the-loop oversight layer; the multi-agent build is underway.
- **TCAF™ (Trustworthy Civic AI Framework)**: my doctoral research. A four-pillar governance architecture (Secure by Architecture · Ethical by Design · Equitable by Intent · Scalable by Design) for evaluating agentic AI in high-stakes civic deployments. Methodology under empirical validation.
- **AccessBridge** *(in development)*: disability-inclusive civic navigation, a sibling TCAF instantiation to PathwayAI.
- **AI education**: four-year AI/STEM instructor (2023–2026) for CSUN's BroSE residential leadership program; led STEM and technology programming at Push Excel, the education arm of Rainbow PUSH Coalition (2015–2022, 2025–2026); 500+ students served through DJMP since 2021.
